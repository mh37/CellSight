# CellSight
Analyze and preview Cellebrite UFDR data

**CellSight** is an open-source, high-performance digital forensics tool designed to preview, parse, and analyze `.ufdr` (Cellebrite Ultra Forensic Data Report) files. Built as a lightweight and enhanced alternative to the standard Cellebrite Reader, CellSight streamlines the investigative workflow by providing deep visibility into mobile extraction data without the bulk.

## Key Features

*   **Instant UFDR Previewing:** Fast, hardware-accelerated rendering of extraction files without tedious indexing delays.
*   **Enhanced Content Parsing:** Advanced deep-dive extraction of standard mobile artifacts (messages, call logs, media, and application data) with improved search and filtering capabilities.
*   **Media Gallery & Timeline Views:** Built-in rich previews for images, videos, and databases directly within the interface.
*   **Developer & Investigator Friendly:** Designed with speed, customizability, and ease of deployment in mind.
